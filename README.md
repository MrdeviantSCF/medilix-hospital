## 🏥 About the Hospital

**MEDILIX HOSPITAL** provides accessible, reliable, and patient-focused healthcare services for the Pathardi community and surrounding areas. The facility operates **24 hours a day, 7 days a week** for emergency admissions and acute care.

### Verified Clinical Services:
- **General Medicine & Primary Care**: Acute illness, fevers, infections, lifestyle disease management.
- **Diabetology & Metabolic Care**: Dedicated blood sugar tracking, insulin initiation, and complication counseling.
- **24/7 Emergency & Casualty**: Immediate priority triage, resident medical officers on standby, and acute stabilization.
- **Diagnostic & Pathology Support Desk**: Rapid hematology, glucose tests, and routine diagnostics.
- **Inpatient Observation Care**: Sanitized, well-ventilated patient observation beds with round-the-clock nursing care.
- **Outpatient (OPD) Consultations**: Scheduled family medicine and visiting specialist clinics.

### Infrastructure & Facilities:
- Wheelchair-accessible entrance, ramps, and corridors.
- Emergency casualty and observation unit.
- On-site pharmacy and diagnostic sample collection.
- Patient and family waiting lounge.

## 🚀 Getting Started

### Prerequisites:
- Node.js (v20+ recommended)
- npm or yarn

### Installation:
```bash
# Clone the repository
git clone https://github.com/MrdeviantSCF/medilix-hospital.git

# Enter project directory
cd medilix-hospital

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build:
```bash
npm run build
npm run preview
```
